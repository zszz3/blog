# wojiecihuo.cn 发布说明

网站已迁移为 Astro Pure 页面布局。原始文章仍在 `src/content/posts/`，图片与文章内容保持不变。

## 当前进度

域名已购买并通过实名认证，根域名和 www 的 A 记录已指向现有阿里云 ECS。个人网站备案已提交，目前需要等待后续审核。服务器上的网站服务与部署凭证尚未配置，GitHub 的自动部署开关默认关闭。

## 每次写作

将 Markdown 与引用的图片一起放进 `src/content/posts/文章目录/`。填写标题、发布日期、简介、标签和分类；`draft: true` 为草稿，发布前改为 `false`。上传主分支后，GitHub Actions 自动检查并生成完整网站，包含搜索索引和 RSS。

## 首次启用服务器部署

备案通过后确认已有网站服务及 80/443 端口占用，选择独立目录和部署账号。已有反向代理时，将博客接入现有代理；需要新建静态服务时可使用 `deploy/Caddyfile` 与 `deploy/compose.yaml`。

目录示例：

```text
/opt/wojiecihuo/
├── deploy/
│   ├── Caddyfile
│   └── compose.yaml
└── site/
    ├── releases/
    ├── shared/
    └── current -> releases/已发布版本
```

部署账号应能写入 `site/`，运行 Caddy 的账号应能读取。首次发布成功后再启动网站服务。

在 GitHub 仓库设置以下 Actions 变量：

| 名称 | 内容 |
| --- | --- |
| `ECS_HOST` | ECS 公网地址 |
| `ECS_USER` | 部署账号 |
| `ECS_PORT` | SSH 端口，默认 22 |
| `ECS_SITE_ROOT` | 独立站点目录，例如 `/opt/wojiecihuo/site` |
| `PUBLIC_ICP_NUMBER` | 审核通过后拿到的真实备案号 |
| `ECS_DEPLOY_ENABLED` | 确认服务器配置完成后设为 `true` |

设置 Actions secrets：

- `ECS_SSH_KEY`：部署账号的专用 SSH 私钥。
- `ECS_KNOWN_HOSTS`：通过可信渠道核对过的服务器主机公钥记录。

不开启部署时，Actions 会保留网站构建文件并说明部署尚未启用。不要把密钥写进仓库。

## 发布与回退

每次提交生成一份完整版本。服务器先验证页面、RSS 与搜索索引，再切换 `current`；构建或验证失败不覆盖当前版本。旧页面用到的带内容指纹的资源会保留，以减少切换时的图片或搜索加载失败。

在 GitHub Actions 手动运行工作流，选择 `rollback`，版本填写 `previous`，可以切回上一版。回退不会改动文章原稿。

首次真实部署完成后，再检查正式域名的 HTTPS、主要页面、中文和代码搜索、图片与 RSS。服务器部署步骤尚未执行，现有预览不代表正式域名已上线。
