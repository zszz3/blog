# wojiecihuo.cn 上线指南

博客已基于现有 Astro / Fuwari 改版，沿用原来的文章、图片和链接，参考 lansganbs.cn 当前的横幅、三栏卡片布局。手机端优先展示文章，文章页提供目录；保留全文搜索、归档、分类、标签、RSS、代码高亮、图片放大和明暗主题。

## 需要买什么

`wojiecihuo.cn` 已购买。接下来完成实名认证和备案即可，暂不需要增加购买项目。已有的阿里云 ECS（2 核 2 GiB、3 Mbps、Ubuntu 22.04）足够承载小型静态个人博客。无需为了这个博客再买数据库、建站套餐或付费 SSL 证书。域名是否可注册及价格以注册页结算信息为准，注意续费价格。

阿里云域名控制台和服务器使用同一个账号，便于管理。域名持有者信息模板需要实名认证，实名身份应与备案主体一致。`www.wojiecihuo.cn` 是该域名下的子域名，无需再买。

## 大陆服务器正式上线顺序

1. 注册域名并完成域名实名认证。
2. 在阿里云备案入口申请个人网站 ICP 备案。服务器位于乌兰察布；包年包月、有公网带宽、购买时长等条件以备案控制台校验为准。
3. 备案通过后，把实际备案号配置为 `PUBLIC_ICP_NUMBER` 再构建，页面底部会自动出现工信部备案查询链接。
4. 确认服务器已有服务和 80/443 端口占用，再选择部署方式。已运行反向代理时，应在已有代理中添加该域名，不能直接启动一个占用相同端口的新服务。
5. 添加 DNS 解析：`@` 和 `www` 两条 A 记录，记录值填服务器控制台显示的公网 IPv4 地址。这里不将服务器地址写入代码仓库。
6. 配置该网站所需的 HTTP/HTTPS 访问，部署后检查 HTTPS、文章链接、归档筛选、搜索、图片和 RSS。公安联网备案等后续事项按所在地要求和备案平台提示完成。

域名已购买，正式部署前仍需确认实名认证和备案状态。服务器上的应用、端口和安全组本次尚未修改；已在 DNS 控制台保存并回读确认 `@` 和 `www` 两条 A 记录指向现有 ECS，TTL 为 10 分钟；新域名的公网 NS 同步仍需等待。

## 本地写作和预览

```sh
pnpm install --frozen-lockfile
pnpm dev
```

默认保持现有 GitHub Pages 地址和 `/blog/` 路径。文章在 `src/content/posts/`，站点标题、头像、导航和横幅在 `src/config.ts`，关于页正文在 `src/content/spec/about.md`。新增文章可执行 `pnpm new-post <文章名>`。

## 为独立域名构建

```sh
SITE_URL=https://wojiecihuo.cn SITE_BASE=/ pnpm build
```

有实际备案号后再构建：

```sh
PUBLIC_ICP_NUMBER='替换为实际备案号' SITE_URL=https://wojiecihuo.cn SITE_BASE=/ pnpm build
```

不要把上述占位备案号用于正式站。最终的 `dist/` 是完整静态站点，不包含运行时数据库，服务器上不需要常驻 Node.js。每次文章更新后，重新构建并更新静态文件。

## 已有服务器没有网站服务时

本项目提供 `deploy/Caddyfile` 和 `deploy/compose.yaml`。Caddy 自动申请及续期 HTTPS 证书。启用前应完成备案、解析，并确认 80/443 未被其他网站或代理占用；服务器需要有 Docker Compose。已有网站服务时，复用已有服务，不直接运行此配置。

把 `dist/` 和 `deploy/` 上传到同一个独立目录，例如 `/opt/wojiecihuo-blog/`，保留结构：

```text
/opt/wojiecihuo-blog/
├── dist/
└── deploy/
    ├── Caddyfile
    └── compose.yaml
```

验证配置后再启动：

```sh
cd /opt/wojiecihuo-blog
docker compose -f deploy/compose.yaml config
docker compose -f deploy/compose.yaml run --rm --no-deps blog caddy validate --config /etc/caddy/Caddyfile
docker compose -f deploy/compose.yaml up -d
```

首次上线前保留已有网站配置和发布包；以后更新时保留上一版 `dist/`，便于回滚。镜像源网络条件、现有服务、端口和证书签发尚需在服务器上实际验证。

## 临时托管预览

`.openai/hosting.json` 保存本次 Sites 预览的标识，独立域名配置不依赖该平台。发布到预览站时使用预览站的 `SITE_URL` 和根路径 `/` 构建；接到阿里云时改用 `https://wojiecihuo.cn` 重新构建。默认 `pnpm build` 仍适用于原有 GitHub Pages 工作流。
