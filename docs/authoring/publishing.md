## 每次提交会发生什么

提交或合并到 `main` 后，GitHub Actions 检查内容并生成页面、图片、全文搜索索引和 RSS，再自动将它们作为同一份版本发布到阿里云。PR 只检查，不发布。

服务器会先接收并检查新版本，确认文件完整后再切换。构建或检查失败不会覆盖原网站。

## 当前状态

自动发布已接通，日常发文无需再次配置服务器或手动进入阿里云。部署凭证保存在 GitHub Secrets 中，不要放进文章或代码。维护步骤见仓库中的 `docs/上线指南.md`。

在 GitHub 网页上传文章和图片、提交到 `main`，也会触发同样的自动发布流程。

## 查看结果

在 GitHub 仓库的 Actions 页面查看当前提交对应的运行结果。构建成功只代表网站文件已经生成；部署步骤成功才表示服务器已经切换到新版本。

## 需要回退时

服务器保留已发布的版本。在 Actions 中选择 `Build and publish blog`，点击 `Run workflow`，操作选择 `rollback`，版本填 `previous`，即可切回上一版。回退不会修改仓库里的文章原稿；下一次提交仍会发布主分支的内容。
