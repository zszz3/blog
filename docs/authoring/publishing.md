## 每次提交会发生什么

提交到主分支后，GitHub Actions 检查内容并生成页面、图片、全文搜索索引和 RSS。它们作为同一份版本发布。

服务器会先接收并检查新版本，确认文件完整后再切换。构建或检查失败不会覆盖原网站。

## 首次启用

服务器地址、部署账号与访问凭证只需要配置一次。具体步骤见仓库中的 `docs/上线指南.md`。

在服务器尚未接通时，Actions 仍会生成可下载的网站文件；正式部署步骤会显示跳过。网站备案通过后再开启正式域名部署。

## 查看结果

在 GitHub 仓库的 Actions 页面查看当前提交对应的运行结果。构建成功只代表网站文件已经生成；部署步骤成功才表示服务器已经切换到新版本。

## 需要回退时

服务器保留已发布的版本。可使用部署工具切回上一版；回退不会修改仓库里的文章原稿。
